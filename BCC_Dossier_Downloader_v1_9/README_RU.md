# BCC Dossier Downloader v1.9

## Что изменилось в v1.9

- Больше не выбирает только один «лучший» ДФЛ и один ДКП.
- В разделах финансового лизинга и купли-продажи скачивает **все важные строки с реальным номером документа**.
- Если реальный ДФЛ не найден, скачивает **все пронумерованные «Заявление о присоединении»** как fallback.
- Акты, допсоглашения, приложения и другие производные документы по-прежнему отбрасываются.
- Нельзя надежно сопоставить ДФЛ и ДКП по номеру, поэтому программа сохраняет все подходящие ДКП.

Пример: если в досье есть `AM2/.../1`, `AM2/.../2`, `AM2/.../3` и три разных номера ДКП, будут сохранены все шесть документов.

# BCC Dossier Downloader v1.3

Программа автоматизирует скачивание нужных документов из «Электронного кредитного досье» BCC.

## Что изменилось в v1.3

- BIN теперь можно ввести прямо в окне программы — TXT/Excel не обязателен.
- Добавлено поле **«Номер досье»**. Если номер указан, программа обрабатывает только совпадающее досье.
- Скачиваются только два нужных вида документов:
  1. **Заявление о присоединении (договор лизинга)**
  2. **Договор купли-продажи**
- Пакетная загрузка BIN из `.xlsx`, `.csv` или `.txt` сохранена как дополнительная возможность.
- Лог `download_log.xlsx` по-прежнему создаётся в папке выгрузки.

## Быстрый запуск

1. Запустите `INSTALL_AND_RUN.bat`.
2. Введите 12-значный BIN в поле **BIN (direct entry)**.
3. Введите **Номер досье**, если у клиента несколько досье и нужно конкретное.
4. Выберите папку для скачивания.
5. Введите BCC username/password так же, как в рабочем BCC (учётные данные не сохраняются).
6. Нажмите **1. Open BCC browser**.
7. После открытия страницы BCC нажмите **2. I am logged in / continue**.

Программа найдёт указанное досье и скачает только два целевых типа документов.

## Пакетный режим

Если нужно обработать много BIN, оставьте поле прямого BIN пустым и выберите `.xlsx`, `.csv` или `.txt` в поле batch mode. Поле «Номер досье» в таком режиме применяется ко всем BIN, поэтому для разных номеров досье удобнее запускать прямой режим по одному клиенту либо подготовить отдельные задания.

## Безопасность

Пароль не записывается в код, конфигурацию или Excel-лог. Он используется только в памяти текущего запуска для HTTP/corporate authentication BCC.

## v1.8 — строгий фильтр договоров

Фильтр теперь принимает решение по полю **Примечание**, а не только по общему полю «Наименование документа».

- «Договор купли-продажи» скачивается только если Примечание относится к самому договору.
- «Акт к договору купли-продажи» не скачивается.
- Договор лизинга / договор финансового лизинга скачивается только как сам договор.
- Акты к договору лизинга не скачиваются.
- Дополнительные соглашения и приложения также исключаются из этих двух целевых типов.


## v1.8 — умный выбор договора

- Сначала ищется полное название договора в поле **Примечание**.
- Если полного названия нет, допускаются сокращения **ДКП** (договор купли-продажи) и **ДФЛ** (договор финансового лизинга), если категория документа это подтверждает.
- Строки с `Акт`, `Допик`, `Дополнительное соглашение`, `Приложение` и другими производными документами исключаются.
- Поле **Номер документа** используется как дополнительный сигнал: реальные номера вида `643/BL/27-07` или `FQ8/2026/...` имеют приоритет над `1`, `-` или пустым значением.
- Для каждого типа выбирается только один лучший кандидат: один договор лизинга и один договор купли-продажи.
