# BCC Electronic Credit Dossier Downloader v1

Программа автоматически собирает документы из внутреннего **Электронного кредитного досье BCC** по списку БИН и сохраняет их в папки на компьютере.

## Что автоматизировано

После входа пользователя в BCC программа:

1. ищет клиента по 12-значному БИН;
2. получает доступные досье клиента;
3. получает все разделы/подразделы документов;
4. получает ID документов;
5. скачивает документы напрямую через штатный BCC endpoint `pkg_w_e_dossier.p_look_document`;
6. сохраняет иерархию `BIN / dossier / category / files`;
7. исключает повторную загрузку одного и того же document ID в рамках БИН;
8. ведёт `download_log.xlsx` со статусом каждого документа и ошибками.

Логин и пароль **не записываются в программу и не сохраняются в файлах**. Пользователь вводит их в обычном окне браузера BCC.

## Установка

Требуется Windows и Python 3.11+.

1. Распакуйте папку программы.
2. Запустите `INSTALL_AND_RUN.bat`.
3. При первом запуске будут установлены Python-пакеты в локальную `.venv`.
4. Программа пытается использовать установленный Microsoft Edge (`msedge`) или Chrome. Поэтому отдельная загрузка браузера Playwright обычно не нужна.

Если в компании `pip install` заблокирован, зависимости нужно будет установить через разрешённый внутренний Python/package repository.

## Входные данные

Поддерживаются `.xlsx`, `.xlsm`, `.csv`, `.txt`.

Программа ищет 12-значный БИН в каждой строке. Для Excel достаточно, чтобы БИН находился в одном из столбцов.

## Запуск

1. Выберите файл со списком БИН.
2. Выберите папку для скачивания.
3. Нажмите **1. Open BCC browser**.
4. В открытом браузере войдите в BCC своим логином/паролем.
5. Если страница поиска БИН не открылась автоматически, перейдите в `Электронное кредитное досье` обычным способом.
6. Вернитесь в окно программы и нажмите **2. I am logged in / continue**.
7. Дождитесь `FINISHED` в журнале программы.

## Результат

Пример:

```text
BCC_Dossiers/
├── 220440010918/
│   ├── Dossier_2216027_.../
│   │   ├── S6_2819_Договор финансового лизинга, акты/
│   │   │   ├── 27394214_....pdf
│   │   │   └── ...
│   │   └── ...
│   └── ...
└── download_log.xlsx
```

Структура остаётся рекурсивной, поэтому её можно передать в существующий folder analyzer.

## Важные ограничения v1

- Версия построена по HAR/HTML, предоставленным 12.08.2026. Если BCC изменит имена endpoint/полей HTML, парсер нужно будет обновить.
- По умолчанию скачиваются **все доступные досье и все доступные категории документов**, чтобы не пропустить данные.
- Если корпоративная сессия истекла во время длинной загрузки, документ будет записан в `download_log.xlsx` как ошибка. Повторный запуск можно делать после нового входа.
- Программа не обходит права доступа BCC: она использует только права текущего вошедшего пользователя.

## Безопасность

Не добавляйте логины, пароли, cookies или Bearer/session tokens в исходный код. Не отправляйте HAR-файлы с активными токенами третьим лицам.
