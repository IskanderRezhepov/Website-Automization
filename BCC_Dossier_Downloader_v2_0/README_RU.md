# BCC Dossier Downloader v2.0 — Contract Pair Grouping

## Что делает v2.0

1. Скачивает **все важные пронумерованные документы** из выбранного досье:
   - ДФЛ / договор лизинга;
   - если ДФЛ отсутствует — пронумерованные `Заявление о присоединении`;
   - все пронумерованные ДКП.
2. После скачивания открывает каждый PDF ДКП и ищет **номер договора лизинга, который прямо указан внутри ДКП**.
3. Создаёт отдельную подпапку на каждый договор лизинга и переносит туда:
   - сам ДФЛ / Заявление о присоединении;
   - все ДКП, которые внутри текста ссылаются именно на этот договор лизинга.
4. Если связь не доказана или неоднозначна, документ **не угадывается** и помещается в `_REVIEW_UNMATCHED`.

Пример структуры:

```
Dossier_.../
  01_LEASE_AM2_2026_U_S_039531_1/
      01_...AM2_2026_U_S_039531_1.pdf
      02_...629_BL_02-07.pdf
  02_LEASE_AM2_2026_U_S_039531_2/
      01_...AM2_2026_U_S_039531_2.pdf
      02_...628_BL_02-07.pdf
  03_LEASE_AM2_2026_U_S_039531_3/
      01_...AM2_2026_U_S_039531_3.pdf
      02_...860_269628.pdf
  _REVIEW_UNMATCHED/          # создаётся только если есть неясные документы
```

Номера ДФЛ и ДКП **не сравниваются между собой** и документы не связываются по порядку или дате. Единственное основание для автоматической пары — внутреннее упоминание номера лизингового договора в PDF ДКП.

## Лог

`download_log.xlsx` теперь содержит лист **Pair grouping** с:
- номером ДКП;
- найденным номером договора лизинга;
- статусом `PAIRED` или `REVIEW`;
- причиной выбора;
- итоговым путём файла.

## Установка

Запустите `INSTALL_AND_RUN.bat`. В v2.0 добавлен PyMuPDF, который используется только для чтения текста уже скачанных PDF при группировке.

## Безопасность

BCC username/password используются только в памяти текущего запуска. Пароль не сохраняется в код, файлы конфигурации или Excel-лог.
