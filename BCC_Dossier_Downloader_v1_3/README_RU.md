# BCC Dossier Downloader v1.3

Программа автоматизирует скачивание нужных документов из «Электронного кредитного досье» BCC.

## Что изменилось в v1.3

- BIN теперь можно ввести прямо в окне программы — TXT/Excel не обязателен.
- Добавлено поле **«Номер досье»**. Если номер указан, программа обрабатывает только совпадающее досье.
- Скачиваются только два нужных вида документов:
  1. **Заявление о присоединении (договор лизинга)**
  2. **Договор купли-продажи**
- Пакетная загрузка BIN из `.xlsx`, `.csv` или `.txt` сохранена как дополнительная возможность.
- Лог `download_log.xlsx` по-прежнему создаётся в папке выгрузки.

## Быстрый запуск

1. Запустите `INSTALL_AND_RUN.bat`.
2. Введите 12-значный BIN в поле **BIN (direct entry)**.
3. Введите **Номер досье**, если у клиента несколько досье и нужно конкретное.
4. Выберите папку для скачивания.
5. Введите BCC username/password так же, как в рабочем BCC (учётные данные не сохраняются).
6. Нажмите **1. Open BCC browser**.
7. После открытия страницы BCC нажмите **2. I am logged in / continue**.

Программа найдёт указанное досье и скачает только два целевых типа документов.

## Пакетный режим

Если нужно обработать много BIN, оставьте поле прямого BIN пустым и выберите `.xlsx`, `.csv` или `.txt` в поле batch mode. Поле «Номер досье» в таком режиме применяется ко всем BIN, поэтому для разных номеров досье удобнее запускать прямой режим по одному клиенту либо подготовить отдельные задания.

## Безопасность

Пароль не записывается в код, конфигурацию или Excel-лог. Он используется только в памяти текущего запуска для HTTP/corporate authentication BCC.
