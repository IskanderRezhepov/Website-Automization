# BCC Dossier Downloader v1.6

Версия v1.6 сохраняет рабочую логику v1.5 и улучшает интерфейс и контроль результата.

## Что нового

### 1. Простой режим одного кейса
Основной экран теперь содержит только поля, которые нужны сотруднику:
- BIN / ИИН
- Номер досье
- Ключ клиента (нужен только если по BIN найдено несколько клиентов)
- Папка сохранения
- BCC username / password
- кнопка **Start**

После Start программа сама открывает Edge, проходит на страницу ЭКД с указанными корпоративными credentials, выполняет поиск и закрывает автоматизированный браузер после завершения. Больше нет отдельной кнопки «I am logged in / continue».

Batch-файл, выбор браузера и URL спрятаны в **Advanced / batch options**.

### 2. Dashboard статуса
На главном экране отображаются:
- Cases completed
- Current BIN
- Current dossier
- Files downloaded
- Skipped
- Not found
- Errors

Отдельно отображается состояние двух обязательных документов:
- Leasing contract / Заявление о присоединении
- Purchase agreement / Договор купли-продажи

Статусы: `WAITING`, `SEARCHING`, `FOUND`, `NOT FOUND`, `ERROR`.

### 3. Отдельный итог по двум документам
`download_log.xlsx` теперь содержит два листа:
- **Download log** — детальный технический журнал файлов
- **Case summary** — одна строка на кейс с отдельными колонками:
  - Leasing contract
  - Purchase agreement
  - Files downloaded
  - Errors

Например:

| BIN | Досье | Leasing contract | Purchase agreement |
|---|---|---|---|
| 220440010918 | NU8/2026/U/S/043581 | FOUND | FOUND |

Если одного документа нет, он явно отмечается `NOT FOUND`.

### 4. Нормализованные имена файлов
Вместо длинных/небезопасных имен BCC файлы получают короткие понятные имена.

Примеры:

`01_Заявление о присоединении_Договор лизинга_№_952505077704991_01.08.2026.pdf`

`02_Договор купли-продажи_№_NU8_2026_U_S_043581_13.08.2026.pdf`

Недопустимые для Windows символы (`/ \\ : * ? " < > |`) автоматически заменяются. Номер документа и дата сохраняются, если BCC их вернул.

## Запуск
1. Распаковать ZIP в отдельную папку.
2. Запустить `INSTALL_AND_RUN.bat` при первом запуске.
3. Заполнить BIN, номер досье и, при необходимости, ключ клиента.
4. Выбрать папку назначения.
5. Ввести корпоративные BCC credentials.
6. Нажать **Start**.

Credentials используются только в памяти текущего запуска и не записываются в файлы или Excel-журнал.

## Какие документы скачиваются
Только:
1. `Заявление о присоединении (Договор лизинга)`
2. `Договор купли-продажи`

## Несколько клиентов на одном BIN
Если найдено несколько клиентов и поле `Ключ клиента` пустое, программа не угадывает клиента и сообщает доступные ключи. Введите нужный `Ключ клиента` и повторите запуск.
