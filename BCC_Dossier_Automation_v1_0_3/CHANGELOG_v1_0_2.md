# v1.0.2

- Исправлен Windows MAX_PATH: короткие имена Excel и короткие пути `_PRODUCTION_READY` / `_QUARANTINE`.
- Tesseract теперь необязателен для запуска всего кейса: OCR-зависимый документ уходит в карантин с `ANALYSIS_FAILED`, остальные документы продолжают обрабатываться.
- Добавлена атомарность пары ДФЛ/ДКП: если один документ пары не прошёл анализ/валидацию, вся пара исключается из `_PRODUCTION_READY`.
- Ошибка одного документа больше не прерывает создание production manifest.
