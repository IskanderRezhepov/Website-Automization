# BCC Dossier Automation v1.0.3

Единое приложение:

**BCC Downloader v2.0 → группировка ДФЛ/ДКП → Analyzer v35.0 → Production Gate**

Excel Merger в эту версию намеренно не включён.

## Что делает один запуск

1. Открывает внутреннее электронное кредитное досье BCC через Playwright.
2. Ищет клиента по БИН/ИИН и, при необходимости, по ключу клиента.
3. Загружает все важные нумерованные документы:
   - ДФЛ / договор лизинга;
   - нумерованные заявления о присоединении как fallback, если ДФЛ отсутствует;
   - все нумерованные договоры купли-продажи.
4. Не скачивает акты, доп. соглашения, приложения и служебные строки как основной договор.
5. Читает каждый ДКП и группирует его с тем ДФЛ/заявлением, номер которого указан внутри ДКП.
6. Неподтверждённые связи помещает в `_REVIEW_UNMATCHED` и **не отправляет их в автоматический production analysis**.
7. Автоматически запускает Analyzer v35 для загруженного дерева каждого БИН/ИИН.
8. Analyzer создаёт Excel и Production Gate:
   - `_PRODUCTION_READY` — только AUTO_APPROVED;
   - `_QUARANTINE` — всё, где есть CHECK/ERROR;
   - `production_manifest.xlsx` — решение по каждому документу.
9. В корне выбранной папки создаётся `integrated_production_manifest.xlsx` с итогом по каждому БИН/ИИН.

## Обычный запуск

Первый раз: `INSTALL_AND_RUN.bat`

Дальше: `RUN.bat`

Введите:
- БИН/ИИН;
- номер досье (если нужен точный фильтр);
- ключ клиента, если у БИН несколько клиентов;
- папку назначения;
- BCC username/password при необходимости.

Нажмите **Start**. После скачивания анализ запускается автоматически.

## Безопасность production gate

Автоматический downstream-процесс должен использовать только Excel из `_PRODUCTION_READY`.

Файлы из `_QUARANTINE` и документы из `_REVIEW_UNMATCHED` не должны автоматически попадать в финальный отчёт/мердж.

Перед каждым повторным анализом старые `_PRODUCTION_READY`, `_QUARANTINE` и `production_manifest.xlsx` для соответствующего БИН очищаются, поэтому устаревшее старое решение не остаётся в production-папке.

## OCR

Для обычных цифровых PDF Tesseract не требуется. Для сканов рекомендуется установить Tesseract OCR. Программа автоматически ищет стандартную установку Windows или путь из `TESSERACT_CMD`.

## Учётные данные

BCC username/password используются только в памяти текущего запуска. Программа не записывает пароль в Excel или на диск.

## Версии компонентов

- Integrated application: 1.0.3
- BCC Downloader: 2.0
- Analyzer: 35.0


## v1.0.3 — Windows path hardening

- Короткие папки клиента и досье: `C_<ключ>` и `D_<id>_<номер досье>`.
- Короткие имена внутри пары: `01_DFL_...`, `01_LEASE_...`, `02_DKP_...`.
- Полное имя клиента, исходное наименование документа, дата и реквизиты сохраняются в `download_log.xlsx`.
- Имена файлов дополнительно подрезаются по бюджету полного пути, чтобы не упираться в классический Windows MAX_PATH.
- Логика выбора, скачивания, связывания ДФЛ/ДКП и Analyzer v35 не изменена.
